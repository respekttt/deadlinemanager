# Definition of Done

Задача (PR) вважається виконаною, коли всі пункти виконано. Кожен пункт перевіряється командою; у CI — через `make ci`.

| ID  | Пункт                                                                               | Перевірка                      |
| --- | ----------------------------------------------------------------------------------- | ------------------------------ |
| D1  | Код відформатовано, лінт без помилок і попереджень.                                 | `make fmt-check lint` (C1, C2) |
| D2  | Межі модулів не порушено: домен і сервіси не знають про SQLite та HTTP.             | `make boundaries` (C3)         |
| D3  | Кожен критерій прийняття зі spec має тест, і всі тести проходять.                   | `make ac-check test` (C4, C5)  |
| D4  | Покриття рядків ≥ 80 %.                                                             | `make coverage` (C6)           |
| D5  | Проєкт збирається з нуля, сервер стартує на порожній БД.                            | `make build smoke` (C7, C8)    |
| D6  | Немає вразливостей рівня high і вище в залежностях.                                 | `make audit` (C9)              |
| D7  | Специфікація відповідає коду: зміни API чи схеми відображені в `standards/spec.md`. | `make spec-check` (C10)        |
| D8  | Роботу з ШІ задокументовано в `ai/prompts-log.md` (і в `ai/sessions/`).             | `make log-check` (C11)         |
| D9  | CI зелений на гілці PR.                                                             | GitHub Actions: `make ci`      |
